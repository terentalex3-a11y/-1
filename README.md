# PostApocalypseRPG

Godot 4 Android 2D post-apocalyptic RPG.

## Vision
20 years after an unknown catastrophe. Top-down Diablo-like exploration with turn-based tactical combat, action points, realistic injuries, scarce ammunition, loot, factions, companions, shelter progression, barter economy and a dynamic world.

## First vertical slice
Explore → loot → encounter/avoid hostile NPC → turn-based combat → injuries/medicine → return to shelter → upgrade gear → save.

## Target
Android APK first; architecture prepared for later expansion.
